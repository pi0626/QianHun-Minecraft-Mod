========================================================================
千魂模组使用说明（1.21.1 / 26.2 双版本）
========================================================================

一、这是什么
------------------------------------------------------------------------
基于高铭小说《千魂》的 Minecraft Fabric 模组。
核心玩法：说真名唤醒千魂书 -> 用心脏温血成为神选者 -> 许愿 ->
AI 把愿望变成命令 -> 服务端最高权限执行 -> 世界上留下"游尸"。

二、装在哪（已经装好了，不用再动）
------------------------------------------------------------------------
1.21.1 版：
  D:\Xw Y\Program Files\Plain Craft Launcher 2\.minecraft\versions\1.21.1-Fabric 0.19.5\mods\qianhun-1.0.0.jar

26.2 版：
  D:\Xw Y\Program Files\Plain Craft Launcher 2\.minecraft\versions\26.2-Fabric 0.19.3\mods\qianhun-1.0.0.jar

前置：只需要 Fabric API。
两个目录里本来就有（1.21.1 是 0.116.17，26.2 是 0.156.0），不用再装。
启动器里直接选对应版本启动即可。

三、怎么玩（按顺序做）
------------------------------------------------------------------------
第 1 步：拿到千魂书
  创造模式物品栏里搜"千魂"，或者用命令：
    /give 你的ID qianhun:qianhun_book

第 2 步：唤醒它
  书刚拿到手是"沉睡"状态（死气沉沉）。
  在聊天框里直接打出它的真名：【千魂书】然后回车。
  书就醒了（封皮开始流动）。

第 3 步：拿到心脏温血
  击杀任何生物，有 25% 概率掉一滴心脏温血。
  也可以 /give 你的ID qianhun:heart_blood

第 4 步：成为神选者（关键，新机制）
  打开背包（E），用鼠标左键拿起心脏温血，
  再点到千魂书上面——就像把一个物品"放"到另一个物品上。
  温血会被消耗一滴，你立刻成为神选者。
  屏幕会提示："心脏温血渗进书页。那些死去的千魂，开始护佑你。"
  右上角会出现一个紫色的"Chosen"图标。

  注意：
  - 已经是神选者再拖，不会再消耗温血。
  - 神选者【不给任何属性加成】，不给护甲、不给幸运，什么都不给。
    它只意味着一件事：那些死去的千魂开始护佑你，你可以许愿。

第 5 步：许愿
  直接在聊天框里说人话，比如：
    给我一把钻石剑
    下雨
    把时间调成白天
  AI（agnes-2.5-flash）会把你的话翻译成命令，服务端用最高权限执行。
  不用加斜杠，说什么都行，中文英文都可以。
  【不掉血、也不再消耗温血】——温血只在第 4 步"印掌纹"那一次用。

  有安全黑名单：/stop /op /ban 这类命令 AI 不会执行。

第 6 步：千魂计数与游尸
  - 任何玩家每杀一个生物，全服千魂计数 +1（不拿书也计数）。
  - 计数存在世界存档里（qianhun_souls.json），重启不丢。
  - 玩家击杀生物时，原地会生成一只"游尸"——照搬那个生物的外形，
    整体压成暗色。白天太阳出来它们就消散。
  - 游尸也能被许愿命令杀掉。

四、命令
------------------------------------------------------------------------
/qianhun status                  看书的状态、计数、游尸存量
/qianhun wish <愿望>             直接许愿（和聊天许愿等价，调试用）
/qianhun spawn <生物ID> [数量]   手动刷游尸（测试用）
/qianhun config <键>             看某个配置
/qianhun config <键> <值>        改配置（需要 OP 权限，2 级）
/qianhun reload                  重读配置文件

常用的几个配置：
  /qianhun config soulthreshold <数值>      许愿需要的千魂数（0 = 不限）
  /qianhun config wishrequiresheartblood <true|false>   许愿是否耗温血
  /qianhun config heartblooddropchance <0~1>            温血掉落概率
  /qianhun config youzhispawnenabled <true|false>       击杀是否生成游尸
  /qianhun config youzhiburnindaylight <true|false>     游尸白天是否消散

五、当前测试用的配置值（你可以自己改回来）
------------------------------------------------------------------------
为了让你一进来就能测，我把两个版本的运行目录配置改成了：
  soulthreshold = 0        （正式玩法建议改回 1000）
  wishrequiresheartblood = false   （温血只在印掌纹那一次用，不再每次许愿扣）
  youzhispawnenabled = true
注意：许愿【不掉血】——原著里许愿本来就不掉血，这个设定已从代码里彻底删除。
改法：进世界后用 /qianhun config soulthreshold 1000 即可。
注意：这些值只影响你自己的测试存档，不影响 mod 本身；
换个新存档会按默认值重新生成配置。

六、神选者到底给什么（你问过的）
------------------------------------------------------------------------
什么都不给。
没有护甲加成、没有幸运、没有任何属性。
它就是一个身份：第一次许愿成功会成为神选者，
或者用心脏温血拖到书上成为神选者。
成为神选者之后，你和其他人没有任何数值区别。

七、已知限制
------------------------------------------------------------------------
- 游尸是静态站姿，四肢不会跟着走路摆动（未实现）。
- 1.21.1 启动时会打一条 "No data fixer registered for qianhun:youzhi"
  的 ERROR 日志，是 Fabric 模组通病，无害，可忽略。
- 游尸的"眼睛模糊一团"这个原著细节没有做。
